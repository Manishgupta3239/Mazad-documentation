ZOHO BOOKS · API V3

Mazad
Zoho Books API

Client-facing API documentation for integrating Mazad with Zoho Books — including customers, vendors, invoices, payments, credit notes, and invoice view URLs.

● Sandbox · Organization ID 941299173

Overview

This documentation describes the APIs provided for the Mazad → Zoho Books integration.

1Identify customerUse the customer ID stored in Mazad.
2Create invoiceSend Mazad invoice information.
3Store invoice IDPersist the returned Zoho invoice ID.
4Collect paymentApply payment to the stored invoice.

Customers

Get Customers

Retrieves customer contacts from Zoho Books using contact_type=customer.

GETGet Customers
https://www.zohoapis.com/books/v3/contacts?organization_id={{organization_id}}&contact_type=customer&page=1
ParameterRequiredDescription
organization_idRequiredZoho Books Sandbox organization ID.
contact_typeRequiredcustomer.
pageRequiredPage number.
per_pageOptionalRecords requested per page.
PaginationIncrease page to retrieve further data. Use per_page to control the number of records per page and continue until no more records are returned.

Recommended Integration Flow

1Get customersRetrieve and paginate customer data.
2Create invoiceUse Mazad's customer ID as mazad_user_id.
3Persist invoice IDSave the returned invoice_id.
4Generate view URLSend the stored invoice ID.
5Receive paymentApply payment against the invoice.
6Retrieve invoiceUse the stored ID for lookups.
7Create credit notePass invoice ID dynamically.
8Keep IDs mappedMaintain Mazad ↔ Zoho identifiers.

Key Integration Rules

Mazad customer identifiermazad_user_id must be the customer's ID stored in the Mazad database.
Tax applicationWhen tax_id is supplied for a line item, the tax applies only to that item.
Tax ID locationFind Tax IDs in Zoho Books → Settings → Taxes.
Store invoice IDStore the returned invoice_id in Mazad for future operations.
PaginationUse page for further data and per_page for page size.
Dynamic IDsSupply customer_id and invoice_id dynamically.
